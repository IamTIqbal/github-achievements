GitHub Achievements are badges that appear on a user's profile (`github.com/<username>` → **Achievements** tab, or directly at `github.com/<username>?tab=achievements`) as a reward for certain activity on the platform — merging pull requests, answering discussions, hitting star milestones on your own repos, sponsoring other developers, and a few limited-time/historical events.

## <img src="assets/icons/info-24.svg" width="20" alt=""> How Achievements Work

- Achievements are awarded automatically based on your public activity on GitHub — there's no manual claim process.
- Most badges have **tiers** (default → bronze → silver → gold) that unlock as your count of the qualifying activity grows. The icon changes style per tier, but they all live under the same achievement name.
- Activity generally must be on **public repositories** to count. Private repo activity is not counted for the community-facing badges.
- A couple of badges are tied to one-time historical events and can no longer be newly earned — see [Badges No Longer Earnable](#-badges-no-longer-earnable).

### <img src="assets/badges/PullShark.png" width="24" alt=""> Pull Shark

<img src="assets/badges/PullShark.png" width="80" alt="Pull Shark badge">

**Earned by:** Having your pull requests merged into a repository (yours or someone else's).

**Tiers:** 2, 16, 128, and 1024 merged pull requests.

**Notes:**
- Merges across multiple different repos generally count faster/more reliably toward tiers than many merges into a single repo you own.
- Reverted or force-pushed-away PRs can still have counted at merge time — the badge reflects merge events, not whether the code survives.

### <img src="assets/badges/GalaxyBrain.png" width="24" alt=""> Galaxy Brain

<img src="assets/badges/GalaxyBrain.png" width="80" alt="Galaxy Brain badge">

**Earned by:** Having a comment marked as the **accepted answer** in a GitHub Discussions thread.

**Tiers:** 2, 8, 16, and 32 accepted answers.

**Notes:**
- Only works in repositories that have Discussions enabled and where a maintainer (or the OP) explicitly marks your reply as the answer.
- Answering in Q&A-format discussion categories is the most reliable way to accumulate this one.

### <img src="assets/badges/PairExtraordinaire.png" width="24" alt=""> Pair Extraordinaire

<img src="assets/badges/PairExtraordinaire.png" width="80" alt="Pair Extraordinaire badge">

**Earned by:** Having a merged pull request that includes a [`Co-authored-by:`](https://docs.github.com/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors) trailer crediting you.

**Tiers:** 1, 10, 24, and 48 co-authored merged PRs.

**Notes:**
- Add co-authors via the `Co-authored-by: Name <email>` trailer in a commit message, or through the GitHub UI/Desktop co-author picker.
- Both the PR author and every listed co-author can earn progress toward this badge from the same merged PR.

### <img src="assets/badges/YOLO.png" width="24" alt=""> YOLO

<img src="assets/badges/YOLO.png" width="80" alt="YOLO badge">

**Earned by:** Merging a pull request without requesting or receiving a review.

**Tiers:** Single tier (no higher levels).

**Notes:**
- This is a one-and-done badge — the first qualifying merge unlocks it permanently.
- Requires being able to merge your own unreviewed PR, so it typically needs write/admin access to the repo (or an unprotected `main`/target branch).

### <img src="assets/badges/QuickDraw_SkinTone1.png" width="24" alt=""> Quickdraw

<img src="assets/badges/QuickDraw_SkinTone1.png" width="80" alt="Quickdraw badge">

**Earned by:** Closing an issue or pull request within 5 minutes of opening it.

**Tiers:** Single tier (no higher levels).

**Notes:**
- Easiest to trigger intentionally: open a throwaway issue/PR in a repo you control, then close it immediately.

### <img src="assets/badges/StarStruck_SkinTone1.png" width="24" alt=""> Starstruck

<img src="assets/badges/StarStruck_SkinTone1.png" width="80" alt="Starstruck badge">

**Earned by:** Owning a repository that attracts a large number of stargazers.

**Tiers:** 16, 128, 512, and 4096 stargazers on a single repository.

**Notes:**
- This is the one badge that depends heavily on external interest/luck rather than direct personal activity — quality/visibility of the project matters more than effort.

### <img src="assets/badges/HeartOnYourSleeve.png" width="24" alt=""> Heart On Your Sleeve

<img src="assets/badges/HeartOnYourSleeve.png" width="80" alt="Heart On Your Sleeve badge">

**Earned by:** Unknown/undocumented. GitHub has never published the exact trigger; it exists on profiles with Default/Bronze/Silver/Gold tiers, but the qualifying action and thresholds aren't confirmed anywhere official.

**Tiers:** Unconfirmed.

### <img src="assets/badges/OpenSourcerer.png" width="24" alt=""> Open Sourcerer

<img src="assets/badges/OpenSourcerer.png" width="80" alt="Open Sourcerer badge">

**Earned by:** Unknown/undocumented. Like Heart On Your Sleeve, it has Default/Bronze/Silver/Gold tiers but no officially published criteria or thresholds.

**Tiers:** Unconfirmed.

### <img src="assets/badges/PublicSponsor.png" width="24" alt=""> Public Sponsor

<img src="assets/badges/PublicSponsor.png" width="80" alt="Public Sponsor badge">

**Earned by:** Sponsoring another developer through [GitHub Sponsors](https://github.com/sponsors).

**Tiers:** Single tier (sponsor at least one person).

## <img src="assets/icons/x-circle-24.svg" width="20" alt=""> Badges No Longer Earnable

These were tied to one-time historical events and can't be newly unlocked today — listed here for reference on profiles that already have them.

### <img src="assets/badges/2020ArcticCodeVaultBadge.png" width="24" alt=""> Arctic Code Vault Contributor

<img src="assets/badges/2020ArcticCodeVaultBadge.png" width="80" alt="Arctic Code Vault Contributor badge">

**Earned by:** Having contributed code to a repository archived in the [2020 GitHub Archive Program](https://archiveprogram.github.com/) — a snapshot of active public repos preserved in the Svalbard Arctic World Archive in February 2020.

**Status:** No longer obtainable — the snapshot was a one-time event tied to repos active in early 2020.

### <img src="assets/badges/Mars2020ContributorBadge.png" width="24" alt=""> Mars 2020 Contributor

<img src="assets/badges/Mars2020ContributorBadge.png" width="80" alt="Mars 2020 Contributor badge">

**Earned by:** Having contributed code to a repository used in the [Mars 2020 Helicopter Mission](https://github.com/readme/featured/nasa-ingenuity-helicopter) (e.g. NASA JPL's F Prime framework).

**Status:** No longer obtainable — tied to contribution activity during the mission's active development window.

## <img src="assets/icons/paintbrush-24.svg" width="20" alt=""> Skin Tone Variants

Some achievement icons — notably **Starstruck** and **Quickdraw** — feature a hand emoji whose skin tone follows your GitHub emoji skin tone preference. Change it under [Settings → Appearance](https://github.com/settings/appearance); the badge on your profile updates to match.

## <img src="assets/icons/eye-24.svg" width="20" alt=""> Viewing and Hiding Achievements

- View your own or anyone else's badges at `https://github.com/<username>?tab=achievements`.
- Achievements are visible on your public profile by default. Opt out from your [profile settings](https://github.com/settings) without losing the underlying earned achievements — they reappear if you re-enable the setting.
- Badges are purely cosmetic — they don't affect permissions, search ranking, or account limits.

## <img src="assets/icons/light-bulb-24.svg" width="20" alt=""> Tips to Unlock the Active Badges

1. **Quickdraw & YOLO first** — both are single-tier and can be earned deliberately in minutes on a repo you control (open+close an issue fast for Quickdraw; merge your own unreviewed PR for YOLO).
2. **Pull Shark** compounds naturally if you contribute to open source regularly — even small doc fixes count once merged.
3. **Pair Extraordinaire** is easy to stack when working with a teammate: just add `Co-authored-by:` trailers on shared commits.
4. **Galaxy Brain** rewards being active and helpful in Discussions-enabled repos — answering setup/troubleshooting questions is a common route.
5. **Public Sponsor** just needs one active [GitHub Sponsors](https://github.com/sponsors) sponsorship, even at the smallest tier.
6. **Starstruck** isn't really "unlockable" on demand — it rewards building something people want to star.

More background on badges in general is in [GitHub's own docs](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/personalizing-your-profile#displaying-badges-on-your-profile).

## <img src="assets/icons/people-24.svg" width="20" alt=""> Contributing

Spotted an outdated tier number or a badge that's missing? Contributions are welcome:

1. Fork the repo and create a branch for your change.
2. Update the relevant section in [`README.md`](README.md).
3. Open a pull request describing what changed and why (a source/link is appreciated for any numeric threshold).
